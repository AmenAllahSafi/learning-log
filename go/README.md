# Go Learning Archive

This directory contains my Go learning exercises, experiments, and practice programs as I work through my Go learning path.

The files are intentionally preserved as learning artifacts: some are small exercises, some are experiments, and some contain mistakes or rough notes that document the learning process.

## Contents

- `exercises/` — day-by-day Go exercises and practice programs
- `playground/` — small standalone experiments from early Go practice

More substantial Go projects will be added here as the learning path progresses.
